# Notts Repeaters

Static site for GB7NR, GB3NF, and GB3NM. It replaces the public pages on gb7nr.co.uk and gb3nf.co.uk.

## Develop

```sh
npm install
npm run dev
```

The dev server runs at http://localhost:4321.

```sh
npm run build
```

`dist/` is the site to publish at nottsrepeaters.org.

## Where facts live

Edit `src/data/stations.ts` when a frequency, mode, or link changes. News-style history is `src/data/history.ts`. The contact address is `src/data/site.ts`.
